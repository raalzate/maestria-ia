# Knowledge Base — Taller IHC

Esta carpeta es la **base de conocimiento** del proyecto. No contiene entregables, sino el contexto que informa cualquier decisión de diseño, redacción o codificación del taller.

## Archivos

| Archivo | Tipo | Propósito |
|---------|------|-----------|
| `propuesta_original.pdf` | PDF | Propuesta original del proyecto IHC entregada como anteproyecto. Versión genérica (3 personas paralelas, dominio difuso). |
| `propuesta_reformulada.md` | Markdown | Propuesta concretada — dominio fijado a banca digital colombiana, persona primaria Carlos (auditor CS), stack Claude API + tool use, MVP delimitado a un flujo. **Esta es la versión vigente.** |
| `taller_enunciado.pdf` | PDF | Enunciado oficial de la Actividad 7 publicado por el curso. |
| `contexto_proyecto.md` | Markdown | Síntesis ejecutiva del problema/solución/persona — referencia rápida para cualquier asistente o colaborador. |

## Cómo usar este KB

- **Cuando se redacte el taller** (HTML, foro, presentaciones): revisar `propuesta_reformulada.md` y `contexto_proyecto.md` para mantener consistencia de dominio, persona, stack, métricas.
- **Cuando se cambie de dominio**: actualizar primero `propuesta_reformulada.md`, luego propagar a `deliverables/taller_resuelto.html`.
- **Cuando se duda de un detalle de la propuesta original**: consultar `propuesta_original.pdf`.

## No tocar

- `propuesta_original.pdf` y `taller_enunciado.pdf` son inmutables — son la versión que el curso ya tiene registrada.
- `propuesta_reformulada.md` y `contexto_proyecto.md` se actualizan según iteración del proyecto.
